# PESTEL Analysis

## Political

- For a real implementation depends on cross-agency cooperation - Civil Protection, INEM, security forces
- Public-sector adoption path: national rollout needs political buy-in, not just technical fit.

## Economic

- None with partnership from official emergency services otherwise there is a risk of API Costs.

## Social

- The public app is positioned to replace "social media/unofficial sources".
- Operator adoption risk.
- Public reception.

## Technological

- Integration with legacy APIs.
- AI/ML needs real training data to certify prediction quality.
- Horizontal scalability

## Environmental

- Domain itself is environment-driven: fire season, weather conditions feed risk forecasting

## Legal

- Liability: AI recommendations require explicit operator confirmation before action
- GDPR / Portuguese data protection
- Classified data / restricted APIs
- Audit log immutability
